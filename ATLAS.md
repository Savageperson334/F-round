# F-round — Repo Atlas

> An intentionally undisciplined index of code fragments, strange tools, micro-projects, research software, abandoned experiments, data and hardware. **Not a dependency list.** The first job is to understand each piece; the second is to dream of combinations.

**Scouting pass:** November 22, 2026. **136 references; 120 unique repositories** across 11 overlapping shelves. The repeated names are deliberate cross-shelf links, not a claim that the same code can be reused without conditions.

**Verification:** Each listed GitHub repository was discovered and its repo metadata inspected in this session. Descriptions are short interpretations of its stated purpose, not a completed code audit. Activity, documentation quality, hardware requirements, and actual functionality differ wildly. No stars are required. An old repo can be valuable inspiration. A repository being public is **not** permission to copy or combine code: check the actual source license and any bundled model/data licenses before importing. Code with no license should be treated as all-rights-reserved unless separately permitted. Archived does not mean unusable.

See [COLLISIONS.md](COLLISIONS.md) for deliberately improbable combinations, [FIELD_GUIDE.md](FIELD_GUIDE.md) for how to evaluate parts, and the [project README](README.md) for F-round's purpose.
