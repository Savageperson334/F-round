# F-round — Back Alleys

**94 additional repo leads** found during the November 22, 2026 GitHub search expedition, bringing the two catalogues together to **214 distinct GitHub repositories**. These are deliberately lower-confidence **scouted leads**, not recommendations or audited dependencies. Every name originated from GitHub repository search; some were also checked individually. No guarantee of license, completeness, quality or maintainership. This is the scratchwork shelf: open a link, inspect what it actually contains, and only then promote it into [ATLAS.md](ATLAS.md).

Not every repo below contains a reusable component. It may be a tiny student's experiment, a fork, a speculative description, or something abandoned. That is allowed for ideas; it is *not* sufficient for a code dependency.
