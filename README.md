# F-round

**Find pieces. Cross wires. Make something the original authors never imagined.**

An open-ended workshop for cross-pollinating GitHub projects: somebody's cave mapper, an abandoned artificial-life experiment, a shortwave decoder, a knitting pattern generator, an odd geochemistry script, a whale-call detector, and whatever bizarre treasure we find tomorrow.

This is neither a startup pitch nor a narrowly focused synth project. The goal is to build **meaningful prototypes from radically unrelated parts**, while remaining free to collect fragments that do not yet make any sense together.

## Enter the chaos

- **[ATLAS.md](ATLAS.md)** — initial enormous list of 120 *distinct* GitHub repositories, arranged into 11 overlapping shelves (136 cross-references).
- **[COLLISIONS.md](COLLISIONS.md)** — 15 cross-repository proposals. Each identifies a reason to exist, a tiny first proof, an absurd extension, and real complications.
- **[FIELD_GUIDE.md](FIELD_GUIDE.md)** — scouting workflow, provenance, adapters, licensing, safety and reproducible prototypes.

## Operating principles

1. **One-person projects are treasures.** A five-star repository can be more creatively valuable than a framework with 50,000.
2. **No theme police.** Music, cartography, fossils, little machines, botany, cryptography, forgotten data, programming languages, zoology, no-category curiosities: everything belongs until proven uninteresting.
3. **Don't demand an immediate fit.** Collect before combining.
4. **An odd result should still do something.** Reveal a connection, tell the truth more vividly, make data tangible, create a useful tool, make an original piece of art, or teach.
5. **Build the simplest bridge first.** Formats (JSON, SVG, WAV, CSV, GeoJSON) beat premature mega-integrations.
6. **Check code rights before copying.** Public GitHub != permission to reuse. Link or reimplement concepts independently when no license is stated.
7. **Reality and fiction have separate labels.** Source-linked measurements and generated artistic output should never be confused.

## First scouting expedition

**2026-11-22.** The linked repos were inspected for project existence and repository-level metadata; this is not a source-code audit of 120 codebases. Some projects are abandoned, archived, unlicensed, hardware-dependent or prototypes. That's okay: we explicitly keep *ideas* separate from *drop-in dependencies*.

The initial objective is to discover genuine collisions, not polish a brand or ship a giant framework.
